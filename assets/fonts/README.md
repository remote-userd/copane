# Bundled font

CaskaydiaMono Nerd Font (Regular, Bold): Cascadia Mono patched with Nerd Fonts icons. The
non-Mono variant: icons are drawn full size and may spill into the next cell, so they don't look
shrunk next to text.
Installed by `bun run install:cli` so the file tree can show file-type icons (see the README, "Icons").

- Source: https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/CascadiaMono.zip (Nerd Fonts v3.4.0)
